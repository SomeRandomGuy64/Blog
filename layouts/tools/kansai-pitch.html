How the pitch is worked out
  • Attested: the word is in an accent dictionary for the region you picked. If that region doesn't have it, the closest Keihan region that does is used, and the page says so. Every region's entry is listed under All recorded pitches.
  • Model prediction: words no dictionary has get the pick of a small neural network trained on the accent dictionaries. It looks at the kanji, the reading, whether the reading is Sino-Japanese or native, and the Tokyo accent when there is one. On words it hadn't seen it gets 80% exactly right with a Tokyo accent and 72% without, against 75% and 60% for the rules below. The % likely right next to it is how often words it scored the same way were exactly right in testing.
  • Rule (verbs and adjectives, when the model can't be used): Kyoto verbs are either high (置く HH) or low and rising at the end (書く LH). For 2-mora verbs and 3-mora 一段 verbs the register follows the Tokyo accent; 3-mora 五段 verbs are high; compounds copy their first verb (92% right on surveyed verbs). Adjectives start high and fall two morae from the end (85%).
  • Guess (nouns, when the model can't be used): learned from every dictionary noun that also has a Tokyo accent, backing off from words with the same first and last kanji to words of the same length. 74% of held-out nouns come out exactly right.
  • Conjugations are Kyoto forms built from the 16-speaker survey's sample verbs: 89% of forms come out exactly right when each sample word is regenerated from the others. Other regions conjugate mostly the same way but weren't surveyed.
API and Anki add-on

Everything on this page comes from a public API. No key is needed, and any site or script may use it. A personal API key (from your profile's Developers section) raises the rate limit.

curl "https://api.fazonnexus.duckdns.org/pitch/word?w=書く&forms=1"

The fazon.nexus domain has expired, so the API is at api.fazonnexus.duckdns.org for now. If you already have the Anki add-on, set API base URL in its settings to https://api.fazonnexus.duckdns.org.

Endpoints, parameters and response fields are documented in the Developer API docs.

Download the Anki add-on It puts Kansai pitch on MvJ note-type cards. It either swaps out the Tokyo pitch the MvJ add-on wrote, or adds pitch to words that have none. Install it with Tools → Add-ons → Install from file…. Its settings choose the region, whether to use guessed pitch, an optional API key, and an optional file of your own pitch for words you've decided yourself.
