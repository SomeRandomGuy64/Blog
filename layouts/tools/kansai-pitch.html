How the pitch is worked out
  • Attested: the word is in an accent dictionary for the region you picked. If that region doesn't have it, the closest Keihan region that does is used, and the page says so. Every region's entry is listed under All recorded pitches.
  • Rule (verbs and adjectives): Kyoto verbs are either high (置く HH) or low and rising at the end (書く LH). For 2-mora verbs and 3-mora 一段 verbs the register follows the Tokyo accent; 3-mora 五段 verbs are high; compounds copy their first verb (92% right on surveyed verbs). Adjectives start high and fall two morae from the end (85%).
  • Guess (nouns): learned from every dictionary noun that also has a Tokyo accent, backing off from words with the same first and last kanji to words of the same length. 74% of held-out nouns come out exactly right, and 82% get the right register.
  • Conjugations are Kyoto forms built from the 16-speaker survey's sample verbs: 89% of forms come out exactly right when each sample word is regenerated from the others. Other regions conjugate mostly the same way but weren't surveyed.
API and Anki add-on

Everything on this page comes from a public API. No key is needed, and any site or script may use it. A personal API key (from your profile's Developers section) raises the rate limit.

curl "https://api.fazon.nexus/pitch/word?w=書く&forms=1"

Endpoints, parameters and response fields are documented in the Developer API docs.

Download the Anki add-on It puts Kansai pitch on MvJ note-type cards. It either swaps out the Tokyo pitch the MvJ add-on wrote, or adds pitch to words that have none. Install it with Tools → Add-ons → Install from file…. Its settings choose the region, whether to use guessed pitch, and an optional API key.
