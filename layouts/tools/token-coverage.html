1 Connect to Anki

What you need
  • Anki open on this computer, with the AnkiConnect and AnkiMorphs add-ons installed.
  • When you press Connect, Anki pops up a window asking whether this site may use AnkiConnect — click Yes. (Or add {{ site.BaseURL | strings.TrimSuffix "/" }} to webCorsOriginList in AnkiConnect's config yourself.)
  • Your browser may also ask to allow access to devices on your local network — allow it, that's how the page talks to Anki. Chrome, Edge and Firefox work; Safari blocks it.
  • The tool only reads your collection (search + note contents). It never changes anything.
